  ---
  Trả lời câu 1: Node.js là gì? Có cần không?

  Node.js là một "phần mềm chạy JavaScript trên máy tính". Bình thường
  JavaScript chỉ chạy trong trình duyệt (Chrome). Node.js cho phép chạy JS ngoài
   trình duyệt – để build website, chạy server.

  Có cần cài không? Có, vì:
  - Next.js (framework mình chọn) cần Node để chạy thử trên máy bạn trước khi
  đưa lên mạng.
  - Claude Code khi tạo dự án cũng dùng các lệnh npm (npm là công cụ đi kèm
  Node).

  → Cài 1 lần dùng mãi mãi, an toàn, miễn phí.

  Cách cài (3 phút):
  1. Vào https://nodejs.org → bấm nút LTS (phiên bản ổn định, màu xanh).
  2. Tải file .msi, chạy, bấm Next → Next → Install. Xong.
  3. Mở PowerShell (gõ powershell ở thanh tìm kiếm Windows), gõ node -v → hiện
  ra số version (vd v20.11.0) là OK.

  ---
  Việc bạn làm ngay bây giờ (song song)

  1. Cài Node.js theo hướng dẫn trên.
  2. Tạo Vercel (1 phút): vào https://vercel.com → bấm Sign Up → chọn Continue 
  with GitHub → cho phép truy cập. Xong, không cần làm gì thêm.

  Khi 2 việc trên xong, báo mình "đã cài Node và có Vercel" → mình sẽ:
  - Tạo thư mục dự án C:\Users\Admin\claude\hsk-vocab\
  - Bảo Claude Code tạo PLAN.md
  - Viết code app từ vựng (Claude tự sinh ~150 từ HSK 1-3 sẵn vào JSON)
  - Hướng dẫn bạn push lên GitHub
  - Deploy Vercel
  - Xuất file transcript cuộc trò chuyện

  Ước tính tổng: 2-3 tiếng là xong và có link nộp thầy. Đi cài Node ngay nhé!
